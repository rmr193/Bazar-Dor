# 🛒 বাজার দর (BazarDor) - দৈনন্দিন পণ্যের সঠিক বাজার মূল্য

> **বাজার দর (BazarDor)** হলো বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর পর্যবেক্ষণ ও সঠিক তথ্য যাচাইয়ের একটি আধুনিক ওয়েব প্ল্যাটফর্ম। কারওয়ান বাজার, খাতুনগঞ্জ সহ সারা দেশের প্রধান পাইকারি ও খুচরা বাজারের সর্বশেষ যাচাইকৃত তথ্যের মাধ্যমে সাধারণ ক্রেতা ও ভোক্তাদের কাছে স্বচ্ছ বাজারদর পৌঁছে দেওয়াই এর মূল লক্ষ্য।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. 🔝 লাইভ প্রাইস টিকার ও ক্যাটাগরি নেভিগেশন (Dynamic Navbar & Price Ticker)
- **ব্র্যান্ড পরিচিতি:** লোগো `🛒 বাজার দর` এবং স্বয়ংক্রিয় আজকের বাংলা তারিখ প্রদর্শন।
- **দ্বি-স্তরীয় নেভিগেশন:** প্রতিটি ক্যাটাগরির নিজস্ব আইকন সহ দ্বিতীয় সারির মেনু এবং অ্যাক্টিভ ক্যাটাগরি হাইলাইট।
- **ইনফিনিট প্রাইস টিকার:** স্ক্রিনের নিচে অবিরাম স্ক্রলিং স্ট্রিপে পণ্যের আজকের দাম ও উঠানামা (▲/▼) শতকরা হার লাইভ প্রদর্শন।

### ২. 🅱️ ইন্টারেক্টিভ হিরো ব্যানার (Hero Section with Anchor Scroll)
- আকর্ষণীয় শিরোনাম, সাবটাইটেল এবং লাইভ মার্কেট হাইলাইটস।
- **স্মুথ স্ক্রল সিটিএ:** "আজকের সব পণ্য দেখুন" বাটনে ক্লিকে কোনো পেজ রিলোড ছাড়াই স্ক্রল করে সরাসরি `#সব-পণ্য` সেকশনে নিয়ে যায়।

### ৩. ⚖️ দৈনিক বাজার ট্রেন্ড ও পণ্যের তালিকা (Market Trends & All Products Grid)
- **সেকশন A (আজ দাম বেড়েছে ▲):** গতকালের তুলনায় সর্বাধিক দাম বৃদ্ধি পাওয়া শীর্ষ ৬টি পণ্য।
- **সেকশন B (আজ দাম কমেছে ▼):** গতকালের তুলনায় সর্বাধিক দাম কমে যাওয়া শীর্ষ ৬টি পণ্য।
- **সেকশন C (সব পণ্য):** ক্যাটাগরি ফিল্টার চিপস, বাংলা/ইংরেজি রিয়েল-টাইম সার্চবার এবং রেসপন্সিভ কার্ড গ্রিড।
- কার্ডে স্পষ্ট থাম্বনেইল ইমোজি, বাংলা নাম, একক (প্রতি কেজি/লিটার/ডজন), আজকের দাম (বাংলা সংখ্যায়) এবং শতকরা পরিবর্তনের ব্যাজ।

### ৪. 🔒 সুরক্ষিত পণ্য বিবরণী ও বাজার বিশ্লেষণ (Protected Product Details `/product/[slug]`)
- **প্রোটেক্টেড রাউট:** লগইন ব্যতীত প্রবেশে স্বয়ংক্রিয়ভাবে টোস্ট নোটিফিকেশন সহ সাইন ইন পেজে রিডাইরেক্ট।
- **দর পরিসংখ্যান:** সর্বনিম্ন দর, সর্বোচ্চ দর এবং জাতীয় গড় বাজারদর কার্ড।
- **ঐতিহাসিক তুলনা:** গতকাল, গত সপ্তাহ ও গত মাসের দরের সাথে আজকের পার্থক্যের তুলনামূলক টাইমলাইন।
- **বাজার ভিত্তিক বিশ্লেষণ:** বিভিন্ন বিভাগ (ঢাকা, চট্টগ্রাম, রাজশাহী ইত্যাদি) অনুসারে ফিল্টারিং এবং বাজারের নাম দিয়ে লাইভ সার্চযোগ্য তুলনামূলক টেবিল।
- **ওয়াচলিস্ট ও শেয়ার:** প্রিয় পণ্যের তালিকায় সংরক্ষণ এবং সরাসরি লিংক শেয়ারিং সুবিধা।

### ৫. 🔐 অথেনটিকেশন ও অ্যাকাউন্ট ব্যবস্থাপনা (Authentication System)
- **সাইন ইন (`/signin`) ও সাইন আপ (`/signup`):** ইমেইল ও পাসওয়ার্ড যাচাইকরণ সহ স্বচ্ছ বাংলা ইন্টারফেস।
- **সোশ্যাল লগইন:** এক ক্লিকে গুগল (Google) ও গিটহাব (GitHub) সোশ্যাল লগইন সুবিধা।
- **ভ্যালিডেশন ও টোস্ট:** রেজিস্ট্রেশন ও লগইনে তাৎক্ষণিক টোস্ট ফিডব্যাক। সফল রেজিস্ট্রেশনের পর লগইন পেজে এবং লগইনের পর হোম পেজে রিডাইরেক্ট।

### ৬. 👤 প্রোফাইল ড্যাশবোর্ড ও ওয়াচলিস্ট (`/profile`)
- ব্যবহারকারীর অবতার, নাম, ইমেইল এবং সদস্য হওয়ার তারিখ।
- **আমার ওয়াচলিস্ট:** সংরক্ষিত পণ্যের তালিকা, বর্তমান দর ও এক ক্লিকে তালিকা থেকে বাদ দেওয়ার সুবিধা।

### ৭. 🛡️ ভোক্তা অধিকার হেল্পলাইন ও ফুটার (Consumer Rights Footer)
- জাতীয় ভোক্তা অধিকার সংরক্ষণ অধিদপ্তরের হটলাইন **১৬১২১** এবং জরুরি সেবা **৯৯৯**-এ সরাসরি কলের সুবিধা।
- ফিগমা নির্ধারিত টেক্সট:
  - *বাম পাশ:* **বাজার দর — প্রয়োজনীয় পণ্যের দাম এক নজরে।**
  - *ডান পাশ:* **সকল দাম সম্ভাব্য; বাজার অবস্থার ওপর নির্ভর করে পরিবর্তিত হয়।**

### ৮. 📱 শতভাগ রেসপন্সিভ ও ফ্রেন্ডলি ৪০৪ পেজ (Responsive & 404 Page)
- মোবাইল, ট্যাবলেট ও ডেস্কটপ সব ডিভাইসের জন্য নিখুঁত লেআউট।
- ভুল বা অজানা ইউআরএলের জন্য সুদৃশ্য বাংলা **৪০৪ পেজ** (`/not-found`) এবং হোমে ফেরার বাটন।

## 🏆 চ্যালেঞ্জ বাস্তবায়ন (Challenge Implementations)

- **C1. সংখ্যাসূচক সর্টিং (Numeric Sorting):** ক্যাটাগরি পেজে `ডিফল্ট`, `দাম: কম থেকে বেশি` এবং `দাম: বেশি থেকে কম` সর্টিং ফিল্টার, যা বাংলা সংখ্যার অভ্যন্তরীণ মান অনুযায়ী নিখুঁতভাবে পণ্য সাজায়।
- **C2. তথ্যবহুল README.md:** প্রজেক্ট নাম, বিবরণ, প্রযুক্তি তালিকা ও ন্যূনতম ৫টি প্রধান ফিচারের বিস্তারিত উপস্থাপন।
- **C3. তথ্য আপডেট ফিচার (Update Information Feature):** প্রোফাইল পেজের "তথ্য আপডেট করুন" বাটনে ক্লিকে আলাদা রাউটে (`/profile/update`) নিয়ে গিয়ে BetterAuth স্পেসিফিকেশন অনুযায়ী নাম পরিবর্তন ও সংরক্ষণ সুবিধা।

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

প্রজেক্টটি আপনার কম্পিউটারে রান করতে নিচের ধাপগুলো অনুসরণ করুন:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/rmr193/Bazar-Dor.git

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd Bazar-Dor

# ৩. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) লিংকে গিয়ে লাইভ ওয়েবসাইটটি দেখুন।

প্রোডাকশন বিল্ড যাচাই করতে:
```bash
npm run build
npm run start
```
